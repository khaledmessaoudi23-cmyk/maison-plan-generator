# Maison Plan Generator

Application mobile MVP pour générer automatiquement des plans de maison en fonction de la surface et du nombre de chambres, avec possibilité de croquis manuel, gestion des étages et sélection des matériaux.

## Fonctionnalités MVP

- Saisie de la surface et du nombre de chambres
- Génération automatique d'un plan de maison
- Sélection du nombre d'étages
- Choix de matériau : standard, premium, luxe
- Aperçu visuel du plan en 2D
- Mode croquis / dessin libre sur la zone du plan
- Simulation de coût selon le matériel choisi

## Run locally

```bash
npm install
npm start
```

Puis lancer l'application dans Android ou iOS via Expo.

## Stack

- React Native
- Expo
- SVG
